## What Git contains

Git contains the frozen input snapshots for the final follow-up analyses.
These snapshots support the offline commands in the [follow-up reproduction guide](../results/followup_suites_20260907/REPRODUCE.md).
Git also contains the model registry, input hashes, training audits, tables, figures, and saved reproduction receipts.

Selected files under otherwise excluded evidence directories support the frozen builders and CPU tests.
These include the historical evaluation prompts, original training banks, source training data, and checkpoint metadata.
The [required source manifest](../results/release_20260909/REQUIRED_SOURCE_FILES.json) lists each file and its hash.
The release preserves the original paths and bytes so the existing provenance checks remain valid.

## Evidence outside Git

The release excludes model weights, raw execution directories, judge databases, exported label intermediates, logs, locks, and duplicate analysis outputs.
The original local files remain unchanged.
Credentials, environments, and caches remain excluded.
The [exclusion manifest](../results/release_20260909/excluded_evidence_manifest.jsonl.gz) records the newly excluded files, sizes, and SHA-256 hashes.
It describes evidence locations and does not contain the evidence itself.
Its paths are relative to the project worktree.

The [private Hugging Face archive](EVIDENCE_ARCHIVE.md) documents the earlier September 6 release.
This Git release does not upload the later evidence to that archive.
A fresh clone can run the CPU tests and reconstruct the final follow-up tables from the committed snapshots.
Full reconstruction from raw judgments, and the name-exchange and Petri reproduction commands, require the corresponding local evidence.
The saved reproduction receipts document the completed checks; they do not make omitted evidence available in a clone.
