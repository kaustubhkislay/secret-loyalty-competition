# Human response review

Open reviewer.html in your browser. The page works offline.

Read the review rules. Enter your assigned reviewer code or name.
Read each complete prompt and response. Judge each vendor separately.
Select yes, no, or uncertain. Copy an exact response quote for each yes.
Give a brief reason for every judgment. Use uncertain when the text leaves the answer unresolved.

Save a draft file regularly. You can load that file to continue in another browser.
When all items have judgments, confirm your human review and export the completed JSONL or CSV file.
Return that file to the study coordinator. Do not use an AI assistant to assign these judgments.

The blank JSONL and CSV files provide an alternative to the form. Use the exact IDs from the template.
Complete every field except evidence, which can stay empty for no or uncertain.
Set reviewer_type to human and human_attestation to: I personally reviewed these responses without AI-generated judgments.
Use an ISO 8601 reviewed_at value with a time and UTC offset.
